# ЛР №1. Парольная защита — вариант 17 (часть 2 — вариант 7)

Java 22 + JavaFX 21 + SQLite (JDBC), архитектура MVVM, корневой пакет `ru.ineprokin`.

## Задание

| Часть | Вариант | Данные варианта |
|---|---|---|
| 1 (табл. 4.1) | 17 | Метод парольной защиты — **простой пароль** |
| 2 (табл. 3) | 7 | P = 10⁻⁶, V = 20 паролей/мин, T = 3 недели |

## Расчёт части 2 (вариант 7)

- V · T = 20 · 60 · 24 · 21 = **604 800** паролей за срок действия
- S\* = ⌈V · T / P⌉ = 604 800 / 10⁻⁶ = **604 800 000 000 ≈ 6,048·10¹¹**
- Условию S\* ≤ A^L удовлетворяют, например:

| Алфавит | A | L | S = A^L | P факт. |
|---|---|---|---|---|
| Цифры | 10 | 12 | 1,00·10¹² | 6,05·10⁻⁷ |
| a–z | 26 | 9 | 5,43·10¹² | 1,11·10⁻⁷ |
| a–z + 0–9 | 36 | 8 | 2,82·10¹² | 2,14·10⁻⁷ |
| a–z, A–Z | 52 | 7 | 1,03·10¹² | 5,88·10⁻⁷ |
| **a–z, A–Z, 0–9** | **62** | **7** | **3,52·10¹²** | **1,72·10⁻⁷** |

Принятый вариант: **A = 62, L = 7** — минимальная длина для этого алфавита,
фактическая вероятность P = 1,72·10⁻⁷ < 10⁻⁶.

## Структура (MVVM)

```
ru.ineprokin
├── Main         точка входа JavaFX (Application)
├── Config       все глобальные константы (политика, данные варианта, форматы, стили)
├── model        Alphabet, SpeedUnit, TimeUnit, PasswordPolicy, PasswordGenerator,
│                StrengthTask/Result/Estimator, AlphabetOption,
│                AuthService, Account, AuthStatus, AuthResponse,
│                Database, UserRepository, StorageBrowser, TableData
├── viewmodel    AuthViewModel, StrengthViewModel, StorageViewModel — JavaFX-свойства
├── view         MainView (TabPane), AuthView, StrengthView, StorageView
└── util         Fmt — форматирование больших чисел
```

Model не зависит от JavaFX и от View; ViewModel не содержит элементов управления;
View связывается с ViewModel только через `bind` / `bindBidirectional` и слушателей свойств.

## Реализованные требования

Часть 1 (простой пароль): регистрация, вход, смена пароля; скрытый ввод;
хранение только соли и SHA-256(соль + пароль); проверка длины (≥ 6), групп символов
и словарных слов; ограничение 3 попыток и блокировка терминала на 15 с с обратным
отсчётом; срок действия пароля 21 день; вывод даты и времени предыдущего входа;
журнал обращений.

Хранилище: база SQLite `lab1.db` создаётся при первом запуске, таблица `users`
(login, salt, hash, changed_at, last_login, failures, lock_until). Учётные записи,
счётчик неудачных попыток, блокировка и время последнего входа переживают перезапуск.
Вкладка «Хранилище (SQLite)» — просмотрщик полей: выбор таблицы, все столбцы и записи,
кнопка обновления (обновляется и при переходе на вкладку).

Часть 2: расчёт V·T, S\*, минимальной длины L для каждого алфавита и фактической
вероятности P; генерация паролей на `SecureRandom` из выбранного алфавита мощности A.

## Сборка и запуск

Сборщик — Gradle (wrapper в репозитории, отдельная установка Gradle не нужна).
Все зависимости — JavaFX 21.0.2 и sqlite-jdbc 3.46.1.3 — подтягиваются автоматически,
никаких jar-файлов в проекте хранить не надо.

```powershell
.\gradlew run          запуск приложения
.\gradlew build        сборка и проверка
```

В PowerShell обязателен префикс `.\` (в `cmd.exe` достаточно `gradlew run`).

Конфигурация — `build.gradle`: плагин `org.openjfx.javafxplugin` сам формирует module-path
для JavaFX, sqlite-jdbc подключается обычной зависимостью через classpath,
исходники берутся из `src` (`sourceSets.main.java.srcDirs`), кодировка компиляции — UTF-8,
toolchain — Java 22.

База `lab1.db` создаётся в рабочем каталоге при первом запуске и в репозиторий не входит.
